# Project LINKS 観光統計

出典: 国土交通省 総合政策局 情報政策課「観光統計データ（2025年度）」

- データセット: https://www.geospatial.jp/ckan/dataset/links_kankoutoukei_2025
- 公式紹介: https://www.mlit.go.jp/links/open-data.html
- 利用条件: 公共データ利用規約（第1.0版）。加工したデータを使っている旨を表示する。

本ディレクトリの3つのCSVは、利用者が提供した公式配布ファイルを変更せず収録したものです。日帰り・宿泊旅行の費用と延べ宿泊者数を、都道府県コードと年で対応付けて使用しています。各CSVは2021〜2024年の47都道府県、188件です。

`src/data/links-tourism.json` は上記CSVをサイト用に加工したものです。

- `AVG_DAY_TRIP_*_COST_PER_PERSON` / `AVG_STAY_TRIP_*_COST_PER_PERSON` を使用。
- 単位は仕様書の「万円／人」。10,000倍して円に変換。
- 合計には元データの `TOTAL_SPENDING` の平均をそのまま使用。費目別平均を合算しない。
- 宿泊費平均も1人・1旅行あたり。1泊あたりの料金として表示したり、泊数を掛けたりしない。
- 空欄は `null` として保持し、ゼロに変換しない。日帰りの宿泊費は表示しない。
- 延べ宿泊者数は `TOTAL_GUEST_COUNT`。仕様書の単位は「人」。画面では万人に換算。
- 宿泊CSVの `(1)` / `(2)` は原本とバイト単位で同一のため、重複収録しない。
- 公演専用の旅行費用や現在のホテル料金、区間別運賃、観光スポットの推薦データではない。

元ファイルを更新した場合は、`scripts/import-links-tourism.py` でJSONを再生成してください。新しいデータセットの名称・対象年はサイトの表示にも合わせて更新してください。

利用者から提供された鉄道・一般旅客自動車の統計は、事業者の年間輸送実績や財務、ランク化された事業情報です。今回の目的地別費用目安に区間別運賃として転用していません。
